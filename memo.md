**Subject:** Support performance analytics and improvement opportunity

## Executive Summary

I built an AI-assisted support analytics dashboard designed to analyze agent-level CSAT and handle-time performance.

The tool is designed to identify performance patterns, surface the bottom ten agents for targeted training consideration, and provide a repeatable validation workflow.

## Current Finding

A production business outcome cannot responsibly be quantified from the available project files because the Vireo data pack referenced in the task brief was not included with the supplied materials.

The application therefore separates:

1. production analysis using the supplied Vireo CSV files, and
2. synthetic demo analysis used only to prove that the application works.

No synthetic metric is presented as an actual Vireo business result.

## What the Tool Measures

The dashboard is designed to calculate:

- CSAT by agent
- Average handle time by agent
- Ticket volume
- Agent-level performance
- Bottom-ten performance
- Data-quality issues
- Potential operational improvement areas

## Recommended Operating Workflow

Once the production data pack is available:

1. Load the five CSV files.
2. Validate required columns and missing values.
3. Calculate ticket-level and agent-level metrics.
4. Compare agent performance.
5. Identify the bottom ten agents using the defined metric methodology.
6. Estimate the business impact using actual Vireo data.
7. Validate a sample of results against source records.

## Limitations

The current submission does not invent a production business outcome because doing so would create an unsupported claim.

The synthetic dataset exists only to demonstrate application functionality.
