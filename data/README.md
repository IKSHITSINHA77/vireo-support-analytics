# Vireo Data Pack

Place the supplied Vireo production data files in this directory.

Expected files:

- tickets.csv
- agents.csv
- orders.csv
- customers.csv
- products.csv

These files are intentionally not generated by the application.

If the files are unavailable, the dashboard can use its synthetic demo dataset for application testing.

## Important

Synthetic data must not be reported as actual Vireo business performance.
