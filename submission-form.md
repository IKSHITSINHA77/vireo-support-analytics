# Vireo Audio — Submission Form

## 1. What did you build?

I built an AI-assisted Streamlit dashboard for Vireo Audio support analytics.

The application is designed to analyze support tickets and calculate:

- CSAT
- Average handle time
- Ticket volume
- Agent-level performance
- Bottom-ten agent performance
- Data-quality issues
- AI-assisted operational insights

The application includes deterministic analytics, validation tests, synthetic demo data for end-to-end testing, and a production-data loading workflow.

### Business outcome

The production business outcome has intentionally not been fabricated.

The task brief requires the business outcome to be calculated from the supplied Vireo data. The referenced production CSV data pack was not included in the available files.

Therefore, no synthetic demo number is represented as actual Vireo performance.

Production validation against Vireo records cannot be completed until the production data pack is supplied.

## 4. Did you change, narrow or push back on the ask?

Yes.

I deliberately separated application validation from production business analysis.

Because the production data pack was unavailable, I did not generate unsupported business conclusions from synthetic data.

This prevents demo values from being presented as real Vireo metrics.

---

## 5. What is wrong, incomplete or shortcut?

The major limitation is the missing production data pack.

The current project therefore cannot provide an evidence-backed production CSAT/handle-time finding or monetary business-impact estimate.

Synthetic data is used only for demonstrating functionality.

---

## 6. What did you deliberately leave out?

I deliberately left out unsupported production conclusions.

I also avoided making an LLM responsible for numerical calculations. Core metrics are calculated deterministically so that results can be tested and reproduced.
